##  Python for Security

A practical learning journey focused on using **Python for cybersecurity, SOC operations, threat hunting, and security automation**.

This repository documents my progress as I learn Python by building small, security-focused tools and gradually moving toward more practical SOC and DFIR automation.

## Objective

My goal is not just to learn Python syntax.

I want to learn how to use Python to:

* Automate repetitive security tasks
* Analyze logs and security data
* Extract and process Indicators of Compromise (IOCs)
* Perform file and hash analysis
* Support SOC investigations
* Automate DFIR tasks
* Interact with security APIs
* Build small tools for threat hunting and incident response

## Learning Approach

I am following a **learn → build → document → improve** approach.

For each project, I try to:

1. Learn the Python concepts required
2. Build a small practical security-related program
3. Document what I learned
4. Identify possible improvements
5. Gradually make the projects more security-focused
